JAVAH BIRTHDAY WEBSITE
======================

Open index.html in a browser.

ADDING THE 20 PHOTOS
--------------------
The current page contains 20 elegant placeholders. To use your own photos:
1. Create a folder named "photos" beside index.html.
2. Put your 20 images there (photo1.jpg through photo20.jpg).
3. In index.html, replace each placeholder inside the gallery with:
   <img src="photos/photo1.jpg" alt="Memory 1">
   and change the number for each photo.

The site is fully responsive and needs no server for the basic version.
